Plan default-workflow: how it fits together

Goal: OpenAFlow ships its own default workflow, reused from a pinned claude-pod release. Each repo keeps everything OpenAFlow-related in one .openaflow/ folder. A workflows/ subfolder holds one folder per workflow, and claude-pod is the first one: the repo commits which version it uses and the workflow's state. The workflow's skills and agents ship in the app. This is plan B of three: terminal-host, then default-workflow, then automatic-input.

my-repo/.openaflow/
└── workflows/
    └── claude-pod/
        ├── workflow.json   { "source": "claude-pod", "version": "0.11.9" }
        └── state/          plans, sprints, queue, decisions

OpenAFlow app: resources/workflows/claude-pod/   skills, agents (bundled)

Parts

PartNew or changedWhereDoes
Workflow locknewpackages/workflowHolds claude-pod's repo, tag, and commit. bump-workflow <tag> rewrites it.
Fetch and transformnewpackages/workflow (build script)Fetches the tag, checks the commit, copies the plugin parts, renames pod-docs, and fails on any leftover. Writes packages/workflow/dist/claude-pod.
App bundlechangedpackages/desktop (build config, install check, notices)Ships the transformed plugin in resources/workflows/claude-pod, beside hooks-plugin.
Repo workflowsnewpackages/modelReads .openaflow/workflows/*/workflow.json and gives each workflow's name, source, version, and state folder. Falls back to pod-docs/ when the repo has no .openaflow/.
Workflow resolvernewpackages/desktop (next to the hooks plugin path)Maps a workflow's source to its bundled folder, packaged or from the repo. This is the seam for a later plugin/ folder.
Session startchangedpackages/desktop, packages/server (session routes)Adds --plugin-dir <workflow> to every hosted claude start. Reports a sideload block as a stop reason.
State readingchangedpackages/model (run model), packages/server (repo files, watcher, queue writer)Reads runs from each workflow's state folder, and writes answers back to the same folder.
Repo setupnewpackages/server (folder list, add repo), packages/webWrites workflow.json and copies the template state after you agree. Rewrites workflow.json on Use <version>.
New session formchangedpackages/web screens/runs, packages/server (skill list)Bare skill names, the version line, the mismatch notice, and the setup offer.
Terminal tabchangedpackages/web screens/runsShows the sideload block message in the stop bar.

Main flow: you add a new repo and start a plan

sequenceDiagram
  actor You
  participant Web
  participant Server
  participant Main as Electron main
  participant Claude as claude
  You->>Web: Add repo
  Web->>You: Create .openaflow/ in this repo?
  You->>Web: Yes
  Web->>Server: set up repo
  Server->>Server: write workflows/claude-pod/workflow.json (app version), copy template state
  You->>Web: New session: pick "plan", type "add tags"
  Web->>Server: POST new session (skill pod:plan)
  Server->>Server: read workflow.json, resolve the bundled claude-pod folder
  Server->>Main: start claude --plugin-dir hooks --plugin-dir workflow "/pod:plan add tags"
  Main->>Claude: spawn in the repo
  Claude->>Claude: writes .openaflow/workflows/claude-pod/state/plans/add-tags.md
  Server-->>Web: board reads the state folder, shows the run

Data

  • Workflow lock (packages/workflow, committed in OpenAFlow; bump-workflow writes it, and the build reads it): repo URL, tag, and commit.
  • Transformed plugin (packages/workflow/dist/claude-pod, not committed; the build writes it, and the app bundle reads it): claude-pod's plugin parts with the new state path, and its LICENSE.
  • workflow.json (<repo>/.openaflow/workflows/<name>/, committed in the repo; repo setup and Use <version> write it, and the server reads it): source and version.
  • Workflow state (<repo>/.openaflow/workflows/<name>/state/, committed in the repo; repo setup creates it, the workflow writes it, and the server reads it): the same files that pod-docs/ holds for claude-pod.
  • pod-docs/ (in a repo with no .openaflow/; claude-pod writes it, and the server reads it): read as today.
