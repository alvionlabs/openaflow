Gaps and angles

Q1 Pin and bundle

  • Submodule pins a SHA, not a tag; needs --recurse-submodules; no auto-update. gotchas. Empty-clone risk is an inference.
  • npm git URLs run install scripts. Claude Code's own npm source forbids git addresses (its fetch only). npm, marketplace-reference
  • No published reference script for "download tag, verify hash, bundle". Old-asset digests not confirmed. GitHub
  • --plugin-dir rejects paths that escape the plugin root, so asar or outside symlinks break. loading
  • Auto-install: npm lockfile registry packages only; for --plugin-dir no evidence found. loading
  • Marketplace cache keyed by version: same version, changed content, no update (#32983, no fix shown). #32983

Name and collisions

  • Names starting claude- fail validate and init/tag; Claude Code still loads them. plugins-reference
  • Same-name --plugin-dir silently replaces the installed plugin; only --debug logs it. loading. Issue #35423 unresolved: link.
  • disableSideloadFlags makes Claude Code exit 1. cli-reference
  • Plugin root CLAUDE.md is not loaded. plugins-reference

Q2 Editable default

  • No per-file override layer; a same-named plugin replaces the whole plugin. loading
  • Notepad++ lost user themes when shipped and user files shared a folder. thread
  • Read-only bundle plus user layer avoids overwrite, but copied-and-edited files never get updates. No failure story fetched.
  • Env vars like CLAUDE_PLUGIN_ROOT reach hooks and MCP/LSP only, not the Bash tool or subagents. plugins-reference

Q3 Rename the state folder

  • No Claude Code way to rename a project state folder was found. claude-directory
  • devsy moved only one of four folders; every workspace broke; reverted. PR #598
  • userConfig under --plugin-dir, or host-preset: no evidence found.
  • No CLI tool found that documents old-name handling.

Best practices

  • Bundle a plain folder via extraResources; resolve with process.resourcesPath; pass --plugin-dir. electron-builder
  • Prefer per-session --plugin-dir to a marketplace install. loading
  • Pin by tag and content hash; keep {repo, tag, sha256} in one committed file. marketplace-reference
  • Set manifest version each release. Run claude plugin validate --strict in CI. plugins-reference
  • Never write into ${CLAUDE_PLUGIN_ROOT}. Use ${CLAUDE_PLUGIN_DATA} or the project.
  • Keep bundle and user edits in separate folders. Notepad++
  • Rename with one host-set env var over a default, plus explicit override. Terraform, git, Cargo
  • Move a renamed folder whole; read the old one when the new is empty. devsy
  • Copier model: tags, stored base, merge, _migrations for one-time moves. configuring

Ideas to consider

Proposals, not facts. (own idea) means the researchers' invention.

  • One resolver function for the plugin path: the seam for a later user workflow. (own idea), grows from electron-builder
  • Seam as an ordered list of plugin dirs; "replace" = same manifest name. grows from loading
  • Read-only bundle plus override plugin; reset = stop passing the user folder. (own idea)
  • workflow.lock.json (repo, tag, sha, sha256) and a bump-workflow <tag> script. (own idea)
  • Build fails if the bundled dir is empty; CI validates it and checks the packaged app. (own idea)
  • If copying later: store {base, files:{path:hash}}; silent update for unchanged, a choice for changed. (own simplification) of Copier
  • One host-set env var for the state folder (default pod-docs); ${user_config.KEY} for skill text, unverified. (own design)
  • Rename on first run: ask once, then move; test with old-name and empty-new fixtures. (own adaptation)
  • Warn at session start if the plugin is also installed, or disableSideloadFlags blocks the flag. (own idea)
  • Use a unique manifest name, or set @inline handling on purpose.
